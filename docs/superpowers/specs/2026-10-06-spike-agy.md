## P1 Salida headless

- `agy -p "<prompt>" --output-format json` → un objeto:
  `{conversation_id, status: "SUCCESS"|"ERROR", response, duration_seconds, num_turns, usage: {input_tokens, output_tokens, thinking_tokens, cache_read_tokens, total_tokens}, denied_actions?}`.
  No reporta el modelo usado ni costo. Fixture: `test/fixtures/agy/print-ok.json`.
- **Prompt por stdin (recomendado):** `--input-format stream-json --output-format stream-json --print=`
  y en stdin una línea NDJSON por turno: `{"event":"user","message":{"content":"<prompt>"}}`.
  Eventos de salida: `init` (conversation_id, model, cwd, tools, permission_mode), `step_update`
  (step_index, state ACTIVE/DONE, step_type, `text_delta`, usage al cerrar), `result` (igual que el JSON de arriba).
  Fixture: `test/fixtures/agy/stream-stdin-ok.jsonl`.
- Trampa: `-p` consume el siguiente token como prompt; con stdin hay que usar `--print=` (vacío, pegado).
- Errores: exit 1/2, `result.status: "ERROR"` con `result.error`, y una línea `error: ...` en stderr.
- **Costo fijo alto:** ~11 600 tokens de entrada por llamada incluso para "ok" (prompt de sistema + ~60 tools).
  Para ahorrar cuota conviene pocos pasos con prompts densos, no muchos pasos chicos.
- Headless no puede pedir permisos: las tools que los requieren se auto-niegan (`denied_actions`).
  Trabajadores que editan archivos necesitan `--dangerously-skip-permissions` (o reglas `permissions.allow`
  en settings.json); también existen `--mode plan|accept-edits` y `--sandbox`.
- `agy models` lista modelos disponibles para la cuenta, incluidos **Claude Opus 5.5 y Sonnet 5.5**
  (low/medium/high), Gemini 3.x y GPT-OSS 120B. Se pasan con `--model <id>`. También `--effort`.

## P5 Spawn desde Node

Funciona con `child_process.spawn(<ruta a agy.exe>, args, { shell: false })` y el prompt por stdin en NDJSON.
Probado con un prompt que contenía `"a & b"` y `%PATH%`: respuesta correcta, nada se ejecutó ni expandió.
→ El adapter de agy **no** usa `runProcess` con `shell: true`: resolver la ruta del `.exe` y lanzar sin shell.
Ojo: desde la sesión de la app el PATH del usuario no incluye `agy`; resolver por `%LOCALAPPDATA%\agy\bin\agy.exe`.
