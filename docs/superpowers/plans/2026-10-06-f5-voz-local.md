> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dictar al chat/`/plan` con whisper.cpp local (el texto cae en la caja para revisarlo) y escuchar respuestas y síntesis con Piper (voz es_MX), todo local.

**Architecture:** `src/voice/` con: `config.ts` (rutas), `text.ts` (markdown → texto hablable, resumen — puro), `whisper.ts` (gestor del proceso `whisper-server`: arranque perezoso, calentamiento, transcripción por HTTP local), `audio.ts` (conversión con ffmpeg), `piper.ts` (síntesis). Rutas `/api/voice/*`. UI: botón de micrófono "mantén para hablar", botón "escuchar" e interruptor de lectura automática.

**Tech Stack:** Node 24 (`fetch`, `FormData`, `Blob`) · TypeScript ESM · Hono · vitest · React 19 (MediaRecorder, `<audio>`).

### Task 2: Whisper (gestor del proceso, calentamiento y transcripción) + ffmpeg
**Files:** `src/voice/whisper.ts`, `src/voice/audio.ts`, tests
**Produces:**
```ts
// audio.ts
export function buildFfmpegArgs(input: string, output: string): string[]; // ["-loglevel","error","-y","-i",input,"-ar","16000","-ac","1","-c:a","pcm_s16le",output]
export async function toWav16k(audio: Buffer, opts?: { run?: Runner }): Promise<Buffer>; // escribe temp, corre ffmpeg, lee y borra
// whisper.ts
export interface WhisperDeps { spawnServer(args: string[]): { kill(): void; onExit(cb: () => void): void }; fetchImpl: typeof fetch; wait(ms: number): Promise<void> }
export function buildWhisperServerArgs(cfg): string[];   // ["-m", model, "--host", "127.0.0.1", "--port", String(port), "-l", "es"]
export function createWhisper(cfg, deps?): { ensureStarted(): Promise<boolean>; transcribe(wav16k: Buffer): Promise<string | null>; status(): "stopped" | "starting" | "warming" | "ready" | "failed"; stop(): void };
export const whisper: ReturnType<typeof createWhisper>;
```
- `ensureStarted`: si ya está listo → true; si no existe el exe o el modelo → `failed` y false; lanza el proceso (sin shell), espera hasta 60 s a que `GET /` responda (poll cada 500 ms), luego **calienta** en segundo plano con 1 s de silencio WAV 16 kHz generado en memoria (estado `warming` hasta que termine, sin bloquear); llamadas concurrentes comparten la misma promesa; si el proceso muere, vuelve a `stopped`.
- `transcribe`: `ensureStarted`, `POST /inference` (FormData `file` Blob `audio/wav`, `response_format=json`, `language=es`), timeout 120 s, devuelve `text.trim()` o `null` si falla (nunca lanza).
- Apagado: `stop()` registrado en `process.on("exit")`, `SIGINT`, `SIGTERM` desde `src/server/index.ts` (Task 4).
- [ ] Tests con deps falsas: args exactos; espera de salud; calentamiento llamado una vez; concurrencia → un solo spawn; exe/modelo faltante → `failed`; respuesta `{text}` → texto; error HTTP/timeout → null; proceso que muere → `stopped` y relanza en la siguiente llamada. ffmpeg: args exactos; `toWav16k` con runner falso escribe y limpia temporales.

### Task 4: Rutas de voz y apagado
**Files:** `src/server/routes/voice.ts`, `src/server/index.ts`, tests
**Produces:**
- `GET /api/voice/status` → `{ whisper: { available: boolean, state }, piper: { available: boolean, voice } }` (`available` = existen exe y modelo/voz).
- `POST /api/voice/transcribe` → body binario (`Content-Type: audio/webm` u otro `audio/*`), 413 si > 10 MB, 415 si no es `audio/*`; `toWav16k` → `whisper.transcribe` → `{ text }`; 503 `{ error }` si Whisper no está disponible o falla.
- `POST /api/voice/speak` `{ text, summary?: boolean }` → `toSpeechText` → `synthesize` → `audio/wav`; 400 si el texto queda vacío; 503 si Piper falla.
- `index.ts`: registrar `whisper.stop()` en salida/señales. No arrancar Whisper al iniciar (perezoso).
- [ ] Tests de rutas con `whisper`/`synthesize`/`toWav16k` simulados.
