# F9 — Toda la app en estilo pixel · Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]`.

**Goal:** aplicar el estilo pixel "C" (VT323 + Silkscreen, marcos de 3 px con sombra dura, esquinas cuadradas,
avatares pixel) a toda la UI sin cambiar comportamiento; el código queda en JetBrains Mono.
Spec: `docs/superpowers/specs/2026-10-15-f9-app-pixel-design.md`. Maqueta aprobada (fuente de verdad visual):
`docs/superpowers/specs/assets/f9-app-pixel-maqueta.html`.

**Architecture:** una capa de tema global en `ui/src/index.css` (fuentes, tokens, clases `px-*`) más cambios de
clases por pantalla; dos helpers puros (`avatarRoleFor`, `statusStyle`) y un `PixelAvatar` que reutiliza
`spriteFrame` de F8.

**Tech Stack:** React 19, Tailwind 4 (`@theme`), vitest (node env). Sin dependencias nuevas.

## Global Constraints
- Rama `f9-app-pixel` desde `f12-oficina-jugable` (actualizado 2026-10-15: ya existen F10 trabajadores, F11 roles y F12 mundo jugable). Solo UI (`ui/`, `test/ui/`); no tocar `src/` (servidor).

Tampoco cambiar `roleColor` de F11.
- Fuentes (ya descargadas y aprobadas) en `C:\tools\fonts\f9\`: `vt323-400.woff2`, `silkscreen-400.woff2`,
  `silkscreen-700.woff2`, `OFL-VT323.txt`, `OFL-Silkscreen.txt` → copiar a `ui/public/fonts/` (y servirlas como
  `/fonts/...`). Nada de CDN.
- Texto: VT323, base ~20 px, nunca < 16 px. Títulos/etiquetas/botones: Silkscreen. Código (bloques y `code` de
  markdown, comandos, rutas, logs de pasos, salidas de agentes): JetBrains Mono, sin cambiar su tamaño actual.
- Marcos: borde 3 px + sombra dura `3px 3px 0 #000`; esquinas cuadradas en toda la app; botón se hunde 2 px al

### Task 1: Capa de tema, fuentes y helpers pixel

**Files:** Create `ui/public/fonts/*` (5 archivos), `ui/src/lib/pixel.ts`, `ui/src/components/PixelAvatar.tsx`;
Modify `ui/src/index.css`; Test `test/ui/pixel.test.ts`.

**Interfaces — Produces:**
```ts
// ui/src/lib/pixel.ts
import type { AgentId } from "./office.js";
export function avatarRoleFor(adapter: string | null | undefined, model?: string | null): AgentId;
//   claude + modelo con "opus" → "jefe"; claude otro → "claude"; codex → "codex"; agy → "agy"; desconocido → "claude"
export type StatusKey = "succeeded"|"completed"|"running"|"paused"|"pending"|"failed"|"cancelled"|"skipped";
export function statusStyle(status: string, paused?: boolean): { icon: string; color: string; label: string };
//   label en español: hecho, completado, ejecutando, pausado, en cola, falló, cancelado, omitido
```
```tsx
// ui/src/components/PixelAvatar.tsx — canvas 28×22 estático (t = 0, working = true) escalado ×2 (56×44), aria-hidden
export function PixelAvatar(props: { role: AgentId; size?: 1 | 2 }): JSX.Element;
```
`index.css`: `@font-face` (VT323 400, Silkscreen 400/700; `font-display: swap`; `url("/fonts/…")`);
no cambiar el `font-size` de `html` (los espaciados en rem se quedan igual); fijar
`body { font-family: "VT323", var(--font-mono); font-size: 20px; line-height: 1.2 }` y subir `--text-xs`,
`--text-sm` y `--text-base` del `@theme` (p. ej. 16/18/20 px) para que ningún texto VT323 quede < 16 px; `--font-mono` sigue
siendo JetBrains Mono y `code, pre, kbd, samp, .font-code { font-family: var(--font-mono); font-size: 13px }`
(tamaño fijo para que el código no crezca con los nuevos `--text-*`); `.font-pixel`
(Silkscreen) para títulos/etiquetas/botones; tokens de radio de Tailwind en 0 (`--radius-*: 0`); clases `px-panel`,
`px-btn` (+ `px-btn-pri`, `px-btn-blue`, estado `:active` hundido, `:disabled` gris), `px-tag`, `px-input`,
`px-grid`, `:focus-visible` con `outline: 2px solid var(--color-accent); outline-offset: 2px`, y
`@media (prefers-reduced-motion: reduce)` que quita transiciones de `px-btn`.
- [ ] Tests de `avatarRoleFor` y `statusStyle` (todos los casos de arriba) → implementar → checks → captura de la
  app tal cual (el tema global ya debe notarse) → commit `feat(ui): tema pixel global, fuentes locales y helpers (F9)`
  → `git push -u origin f9-app-pixel`.
