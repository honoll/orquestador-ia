# F8 — Vista Oficina · Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]`.

**Goal:** vista "Oficina" pixel-art al lado del Chat que muestra en vivo qué hace cada agente del orquestador.
Spec: `docs/superpowers/specs/2026-10-15-f8-oficina-design.md`. Maqueta aprobada (referencia visual y de código de
los sprites): `docs/superpowers/specs/assets/f8-oficina-maqueta.html`.

**Architecture:** el servidor arma una foto pura (`buildOfficeState`) desde la base y el estado en memoria y la
expone en `GET /api/office/state`; la UI la pide y la refresca con eventos WS; los sprites se dibujan en `<canvas>`
con una función pura `spriteFrame`.

**Tech Stack:** Hono + Drizzle/libsql, React 19 + TanStack Query + Tailwind 4, vitest (node env). Sin deps nuevas.

## Global Constraints
- Rama `f8-oficina` creada desde `f7-app-escritorio` (puerto 3110).
- Elenco, colores y accesorios EXACTOS de la tabla del spec (jefe `#a78bfa` sombrero; guardia `#fbbf24` gorra;
  agy `#60a5fa` antena; codex `#34d399` lentes; claude `#e879f9` moño; biblio `#f472b6` libros; recepcion
  `#fb923c` diadema). Ids: `"jefe"|"guardia"|"agy"|"codex"|"claude"|"biblio"|"recepcion"`.
- Ventanas: guardia trabaja 8 s tras `plan:tier`/`plan:guard`; biblio 20 s tras `plan:memory` con `source:"loading"`.
- Escritorios por personaje: mín. 1, máx. 4; etiqueta "×N" si N > 1. Cola máx. 20, `running` primero.
- Sprite 28×22 escalado ×4, `image-rendering: pixelated`, 4 cuadros/s solo si trabaja y la pestaña es visible;
  `prefers-reduced-motion` → sin animación. Escena `aria-hidden`; textos en reposo con contraste ≥ 4.5:1.
- Refresco por eventos WS con debounce 300 ms; reintento cada 10 s si la foto falla. Log: últimos 100 eventos.
- Textos de UI en español de México. Sin dependencias ni fuentes nuevas.

### Task 1: Foto del estado de la oficina (servidor)

**Files:** Create `src/server/office-state.ts`, `src/server/routes/office.ts`; Modify `src/server/index.ts`
(montar `/api/office`, arrancar el recolector de marcas); Test `test/server/office-state.test.ts`,
`test/server/office-routes.test.ts`.

**Interfaces — Produces:**
```ts
export type AgentId = "jefe"|"guardia"|"agy"|"codex"|"claude"|"biblio"|"recepcion";
export interface AgentState { id: AgentId; working: boolean; desks: number; activity: string; model: string; tokens: number; paused?: boolean }
export interface QueueItem { planId: string; stepId: string; stepKey: string | null; description: string; adapter: string; status: "running"|"pending"|"paused"; project: string | null }
export interface PlanSummary { id: string; description: string; status: string; pauseReason: string | null; updatedAt: string }
export interface OfficeState { agents: AgentState[]; queue: QueueItem[]; plans: PlanSummary[]; generatedAt: string }
export interface OfficeInput {
  now: number;
  generatingPlans: { id: string; description: string }[];
  synthesisRunning: { id: string; description: string }[];
  steps: { planId: string; stepId: string; stepKey: string | null; description: string; adapter: string; model: string | null; status: string; guardPaused: boolean; project: string | null }[];
  chatRuns: { adapter: string; model: string | null; prompt: string }[];
  tokensByAdapter: Record<string, number>;   // desde SERVER_STARTED_AT (runs + agy_usage)
  lastTierOrGuardAt: number | null; guardPausedCount: number;
  memoryIndexing: boolean; lastMemoryLoadingAt: number | null; memoryNotes: number;
  voiceActive: boolean; whisperState: string;
  recentPlans: PlanSummary[];                 // últimos 8 por updated_at
}
export function buildOfficeState(input: OfficeInput): OfficeState;   // PURA
export async function collectOfficeInput(now?: number): Promise<OfficeInput>;
export function startOfficeEventTracker(): void; // onBroadcast: guarda timestamps de plan:tier, plan:guard, plan:memory loading
```
Reglas de `buildOfficeState`: jefe trabaja si hay `generatingPlans` o `synthesisRunning` (activity = "planeando: <desc>"
o "sintetizando: <desc>", model "Opus 5.5"); guardia si `now - lastTierOrGuardAt ≤ 8000`, `paused = guardPausedCount > 0`
(activity "pausó N paso(s)" si paused); agy/codex/claude: N = pasos `running` de ese adaptador + chatRuns de ese
adaptador; `working = N > 0`; `desks = clamp(N,1,4)`; activity = descripción del primer paso o "chat"; model = el del
paso/run o el por defecto del adaptador (de `src/config/models.ts`); biblio si `memoryIndexing` o `now -
lastMemoryLoadingAt ≤ 20000` (activity "indexando"/"buscando notas", si no "<memoryNotes> notas · listo");
recepcion si `voiceActive` o `whisperState ∈ {starting, warming}`. `tokens`: agy/codex/claude =
`tokensByAdapter[adapter] ?? 0`; jefe, guardia, biblio y recepcion = 0 (la UI muestra "—"), con el comentario
`// shortcut: planner/síntesis no guardan tokens por separado; sumar plans.used_tokens si se quiere el del jefe`. Cola: pasos `running` (primero), luego `pending`; `status:"paused"` si `guardPaused`; máx. 20.
`SERVER_STARTED_AT`: exportarlo desde `src/server/routes/usage.ts` y reutilizarlo (no duplicar la consulta de tiempo).
Ruta: `GET /api/office/state` → 200 `OfficeState`; error → 500 `{ error }`.

- [ ] Tests primero (un caso por regla, ventanas con `now` inyectado, clamp de escritorios, orden/truncado de la cola)
  → implementar → checks → commit `feat(oficina): foto del estado de la oficina (F8)` → `git push -u origin f8-oficina`.

**Interfaces — Produces:**
```ts
export type Rect = [x: number, y: number, w: number, h: number, color: string];
export const SPRITE_W = 28, SPRITE_H = 22;
export const ROLES: Record<AgentId, { label: string; color: string; accessory: "sombrero"|"gorra"|"antena"|"lentes"|"moño"|"libros"|"diadema"; zone: "direccion"|"trabajadores"|"servicios" }>;
export function shade(hex: string, f: number): string;
export function spriteFrame(role: AgentId, working: boolean, t: number): Rect[];
export function deskLabel(label: string, desks: number): string;          // "AGY ×2"
export function eventToLog(ev: { type: string; [k: string]: unknown }, now?: Date): { time: string; agent: AgentId; text: string; color: string } | null;
```
`spriteFrame` porta el dibujo de la maqueta (`draw()` en `f8-oficina-maqueta.html`) a una lista de rectángulos
(escritorio, monitor con texto si trabaja, teclado, cuerpo, brazo, cabeza 3 tonos, cara, ojos/ojos cerrados,
accesorio, "z" en reposo como rectángulos). `AgentSprite` = `<canvas width=28 height=22>` CSS 112×88, dibuja
`spriteFrame`, intervalo 250 ms solo si `working && !document.hidden && !reducedMotion`, limpia en unmount.
`eventToLog`: `plan:ready`→jefe "plan listo", `plan:synthesis` succeeded→jefe, `plan:tier`→guardia "tier <x>",
`plan:guard`→guardia "pausó un paso", `plan:step` running/succeeded/failed→el personaje de `ev.adapter` si el
evento lo trae (agregar `adapter` al payload de `plan:step` en `plan-runner.ts`/`plan-scheduler.ts` es parte de esta
tarea; si falta, devolver null), `plan:memory`→biblio, `memory:indexed`→biblio, `voice:assistant:turn-done`
→recepcion, `plan:done`→jefe con estado; otros → null.
